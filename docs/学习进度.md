- [x] **11. 测试数据清理** —— `yield` 与 teardown，保证失败也不留垃圾数据

## 教学方式约定（我自己遵守的规矩）

1. 单轮代码 ≤30 行，一个概念
2. 先给料（文档/字段/坑/示例），再派活
3. 代码由你写，我不代写
4. 不无限追问；每轮最多一个问题
5. 同一处第二次说"不懂" → 换载体（真机/动画/图），不用文字讲第三遍
6. 有具体证据的认可，不空夸
7. 每完成一个小目标报进度
